# 如果你喜欢本mod，也欢迎看看我的其它mod。或许对你有帮助。

## ① 效果

将游戏中的“火箭飞拳”卡牌的效果由 111 版本的“生成状态牌时耗能减少 1”回调为 110 版本之前的“生成状态牌时耗能降为 0”。

其余效果保持不变：2 费攻击牌，造成 13 点伤害（升级后 14 点），抽 1 张牌（升级后 2 张）；卡面文本同步还原为旧版文案，卡图不变。

本 mod 直接在“火箭飞拳”原卡牌上进行修改，并非生成新卡牌 + 禁用旧卡牌。

## ② 影响（基于本人游戏理解）

110版本之前的火箭飞拳是可以无脑带一张的优质过渡/运转终端组件，只要有一张生成状态牌的牌，那么就有50%以上的概率可以用0费打出，且从第二轮洗牌开始几乎可以稳定0费打出。

而110版本的改动令其大幅削弱，不仅前期的过渡作用极大削弱，即便后期作为核心运转组件时也变得格外需要注意打出的顺序，让人感到不习惯。

本 mod 影响存档：在 mod 开启时，历史记录中的“火箭飞拳”卡牌描述按回调后的文案显示；关闭 mod 后会恢复原状。

## ③ 环境与版本

本 mod 不依赖任何基础 mod。

本 mod 在 0.110.0 及以上版本生效（当前 0.111.0 即生效）；

在 0.099.x~0.109.x 上自动停用：该版本区间的火箭飞拳本就是目标效果，无须修改。

游戏运行时 Mod 检测当前游戏版本号和游戏包体是否存在火箭飞拳卡牌：版本低于110或火箭飞拳卡牌被移除时，本 mod 自动不生效，不会报错或崩溃；

理论上只要没有大的 api 更新或卡牌修改，本 mod 无须修改即可自动适配新版本。

## ④ 语言支持

本 mod 的卡面描述共提供 15 种语言——deu / eng / esp / fra / ita / jpn / kor / pol / ptb / rus / spa / tha / tur / zhs / zht。

其中 14 种语言与 v0.107.1 官方文本完全一致；zht（繁体中文）因 107 版本官方未提供，采用 v0.111.0 官方繁中文本修改。

其余107版本未提供的语言（ ind ）不替换描述，保持显示官方 111 版本文案不变、但卡牌效果已经替换，不会报错。

## ⑤ 实现方式与兼容性

本 mod 采用最小依赖的方式写成，正常来说与大多数 mod 兼容，且不易随着版本变化而失效。

本 mod 采用外置补丁写死的方式，将火箭飞拳卡牌的卡面文本（描述）与降费触发效果固定为 110 版本前的效果；卡名保持官方原样、其余内容未写死。

本 mod 在不同游戏版本的生效方式均相同。

但本 mod 不保证与盗版、修改版、移动版、老旧版本或者冷门 mod、次级 mod 的兼容性。

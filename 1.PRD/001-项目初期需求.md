# 001 项目初期需求

- 项目：回调火箭飞拳（RevertRocketPunch）
- 建档时间：2026-11-19 00:24
- 当前版本：1.1.0（开发中，发版前为 1.0）
- 目标游戏：正式版 0.111.1、beta 版 0.113.1

## 项目目标与成功判据

把故障机器人卡牌「火箭飞拳」（`RocketPunch`）回调为 v0.110 之前的效果：每当你生成状态牌时，此牌的耗能降为 0，直到打出。卡面描述同步显示「降为 0」。

成功判据：

1. 在 0.111.1 与 0.113.1 上，同一份 DLL 能加载、能安装补丁、不抛异常。
2. 玩家生成状态牌后，手牌中的火箭飞拳费用显示为 0，且实际打出消耗 0 能量。
3. 卡面描述与实际效果一致。
4. 版本低于 0.110 或卡牌不存在时，mod 不介入，游戏保持原版行为。

## 非目标

- 不新增卡牌，不禁用原卡，不改卡名、卡图、基础数值。
- 不回调 `OnPlay` 的 `FromCard(this)` → `FromCard(this, cardPlay)` 签名变化；该变化没有玩家可见效果。
- 不兼容 0.103.2 及更早版本。该区间的方法签名为 `(CardModel, bool)`，与当前补丁不匹配。
- 不为 0.113.0 单独维护。该版本已由参考库标注为弃用。
- 不修改游戏存档结构。

## 用户与使用场景

- 用户：在 Steam 上使用正式版 0.111.1 或 beta 版 0.113.1 的《杀戮尖塔 2》玩家。
- 场景：故障机器人对局中打出生成状态牌的效果；或通过图鉴查看火箭飞拳卡面。
- 场景：用户切换 Steam 分支后，不更换 mod 文件，继续使用同一份 DLL。

## 功能需求

### RQ-001 效果回调

- 优先级：高
- 验收标准：对局中，己方火箭飞拳在手；己方生成一张状态牌后，该卡 `EnergyCost.GetResolved()` 为 0；连续生成状态牌仍为 0；打出后修饰符失效。
- 状态：已实现
- 来源：用户要求（2026-08-20）

### RQ-002 卡面文本回调

- 优先级：高
- 验收标准：受支持语言下，火箭飞拳描述显示「降为 0 / to 0」语义；键为 `RE_ROCKET_PUNCH.description`；缺失键时不抛 `LocException`。
- 状态：已实现
- 来源：用户要求（2026-08-20）

### RQ-003 版本门与安全降级

- 优先级：中
- 验收标准：`Major == 0 && Minor >= 110` 时补丁启用；低于 0.110 时所有补丁路径放行原版；版本读不到时不崩溃并重试；卡牌检查失败时只告警一次。
- 状态：已实现
- 来源：用户要求、ADR-001

### RQ-004 0.111.1 与 0.113.1 双版本兼容

- 状态：已实现

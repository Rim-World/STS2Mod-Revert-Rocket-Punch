# 施工计划：回调飞拳（RevertRocketPunch）——火箭飞拳回调至 v0.110 之前效果

- 状态：**v1.0.2 文本已对齐官方 107（fra/spa 修正 NBSP）并重建安装；参考库 STS2107CardReference 已建立（ADR-003）**

- 安装目标：`C:\Game\Steam\steamapps\common\Slay the Spire 2\mods\`

## 1. 需求

将故障机器人（Defect）卡牌「火箭飞拳」（Rocket Punch）在 v0.110 起被削弱的触发效果，回调为 v0.110 之前（v0.107.1 确认）的效果：

| 项 | v0.107.1（回调目标） | v0.110+ / v0.111.0（当前） |
|---|---|---|
| 触发 | 每当你生成状态牌时 | 同左 |
| 费用变化 | **降为 0**（`SetUntilPlayed(0)`，绝对修饰符） | **减少 1**（`AddUntilPlayed(-1)`，相对修饰符） |
| 其余 | 2 费 / 攻击 / 罕见 / 任意敌人 / 13(+1) 伤害 / 抽 1(+1) 张 | 无差异（不回调） |

## 2. 目标效果（写死定义）

生成状态牌后，火箭飞拳费用绝对设为 0，直至打出。三次守卫与 107 一致：

```
creator == 卡主 && 生成的牌属于卡主 && 生成的牌是 Status → EnergyCost.SetUntilPlayed(0)
```

### 3.2 核心效果补丁（Prefix 全部路径短路，与 CustomCardBalance 同构）

```csharp
[HarmonyPatch(typeof(RocketPunch), "AfterCardGeneratedForCombat")]
public static class RocketPunchGeneratedStatusPatch
{
    public static bool Prefix(RocketPunch __instance, CardModel card, Player? creator, ref Task __result)
    {
        if (!ModConfig.IsReplaceEnabled) return true;          // 版本门/守卫未通过 → 原版行为
        if (creator != __instance.Owner || card.Owner != __instance.Owner || card.Type != CardType.Status)
        {
            __result = Task.CompletedTask;                      // 与 107 守卫分支一致
            return false;
        }
        __instance.EnergyCost.SetUntilPlayed(0);                // 107 效果
        __result = Task.CompletedTask;
        return false;
    }
}
```

### 3.3 描述文本

- 方案 A（推荐）：**切键模式**（回调同步先例）——pck 内 `localization/{lang}/cards.json` 提供 `RE_ROCKET_PUNCH.description`，patch `CardModel.Description` getter 对 `RocketPunch` 实例切换到新键；`RE_` 前缀避免与 CustomCardBalance 等 mod 的官方键覆写冲突。
- 方案 B：直接覆写官方键 `ROCKET_PUNCH.description`（CustomCardBalance 先例，纯 DLL 无 pck，但与同覆写该键的 mod 存在 patch 顺序竞争）。
- 文本内容 = 107 语义（「降为 0 / to 0」，模板与 111 官方同构），15 语言（CustomCardBalance 14 语言 + zht 转写，不含 ind；决策 D2/D4）。

### 3.4 卡存在性检查与版本门

- `RocketPunchGuard.IsSupported()`：运行时 `ModelDb.Card<RocketPunch>()` 存在性检查（未来版本删除该卡 → 补丁禁用 + Log.Warn，不崩溃）；**仅在补丁运行时首次触发时懒评估（ModelDb 此时必然已就绪），ModLoaded 阶段禁止访问 ModelDb（ADR-002）**。**不做静态形状守卫**（用户决策 2026-08-20）。
- `ModConfig.IsReplaceEnabled`：卡存在性检查通过 且 `ReleaseInfoManager.Instance.SemVer.Minor >= 110`（107/108/109 已是目标效果，不干预；110+ 一律生效）。

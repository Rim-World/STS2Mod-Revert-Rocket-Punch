# 002-M：0.111.1 与 0.113.1 双版本兼容

- 层级：M（子系统/阶段性目标）
- 状态：已完成（0.113.1 已验证；0.111.1 运行验证待用户）
- 建立时间：2026-11-19 00:24
- 关联需求：RQ-004、RQ-006
- 关联 ADR：ADR-004
- 关联文档：`3.DOCS/003-E-111.1与113.1兼容性核验.md`

## 目标

用同一份发布 DLL 同时支持正式版 0.111.1 与 beta 版 0.113.1，并修复 `ind` 语言文本与效果不一致的问题。

## 前置证据

- 参考库 `2.STS2-111Reference/assemblies/sts2.dll` 为 0.111.1 程序集，SHA-256 `3fb1fa1b…`。
- 参考库 `4.STS2-113.1Reference/assemblies/sts2.dll` 为 0.113.1 程序集，SHA-256 `62ecbe91…`。
- `RocketPunch.cs` 两版逐字节相同；`CardEnergyCost.SetUntilPlayed`、`CardModel.Description`、`LocString`、`ReleaseInfoManager`、`ModManager` 无影响本 mod 的差异。
- 两版都支持 `ind`；0.113.1 新增 `ara`，官方阿拉伯语文本已经是「降为 0」。

## 实施步骤

1. 在 `RocketPunchTextPatch.IsSupportedLanguage` 白名单加入 `ind`。
2. 在本地化生成脚本中加入 `ind`，输出 `menjadi 0` 语义；脚本路径从旧 `src/` 改到 `9.SRC/`。
3. 在 `export_presets.cfg` 的 `export_files` 加入 `ind/cards.json`。
4. manifest 版本升至 `1.1.0`。
5. `build.ps1` 增加 `-Sts2DataDir` 参数，用 0.111.1 程序集构建。
6. 构建前运行 `8.TEST/CI-CD/verify-version.ps1`。
7. 在 0.113.1 上用场景探针验证效果与文本；0.111.1 运行验证交给用户。

## 验证

- [x] 源码分别引用 0.111.1、0.113.1 的 `sts2.dll` 编译通过，0 警告 0 错误。
- [x] 两份编译产物的 `call`/`ldftn`/`newobj` 成员引用集合一致。
- [x] 以 0.111.1 程序集构建 v1.1.0，`ind/cards.json` 进入 pck。
- [x] 0.113.1 无头加载与场景探针通过（2026-11-19 00:38）。
- [ ] 0.111.1 运行验证（用户切换 Steam 分支后执行）。

## 风险

- 0.113.1 后续小版本可能再次改动 `RocketPunch.cs` 或相关 API；每次更新后按 SPEC 与 DOCS 的清单复核。
- `ara` 依赖官方文本保持「降为 0」；若官方改回「减少 1」，需要重新评估。

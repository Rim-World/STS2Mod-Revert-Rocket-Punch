# 001 总体规范

- SPEC 版本：1.0
- 生效时间：2026-11-19 00:24
- 适用版本：RevertRocketPunch 1.1.0
- 适用游戏：0.111.1、0.113.1

## 1. 效果

**SP-001** 当己方生成一张状态牌后，己方拥有的每张「火箭飞拳」的当前费用必须为 0，直到该牌打出。

**SP-002** 只有当生成者为火箭飞拳的拥有者、生成的牌属于该拥有者、且生成的牌类型为 `Status` 时，mod 才可以修改费用。

## 2. 文本

**SP-003** 在受支持语言下，火箭飞拳的描述文本必须表达「费用降为 0，直到打出」，不得表达「费用减少 1」。

**SP-004** 受支持语言集合必须为 `deu/eng/esp/fra/ind/ita/jpn/kor/pol/ptb/rus/spa/tha/tur/zhs/zht`。`ara` 不切键，因为 0.113.1 官方阿拉伯语文本已经表达「降为 0」。

**SP-005** 每个受支持语言必须在 `res://RevertRocketPunch/localization/<lang>/cards.json` 提供 `RE_ROCKET_PUNCH.description` 键。

**SP-006** 描述补丁必须只对 `RocketPunch` 实例和受支持语言生效，不得影响其他卡牌或其他语言。

## 3. 版本与降级

**SP-007** 仅当游戏版本满足 `Major == 0 && Minor >= 110` 时，mod 才可以改变效果与文本。

**SP-008** 游戏版本低于 0.110 时，mod 必须放行原版行为，不得修改费用或文本。

**SP-009** 版本号读取失败时，mod 不得中断游戏，必须记录警告并在下次访问时重试。

**SP-010** 卡牌存在性检查失败时，mod 不得中断游戏，必须记录一次警告；补丁不得因此跳过安装。

## 4. 双版本兼容

**SP-011** 发布用 DLL 必须以 0.111.1 的 `sts2.dll` 为编译基线，且同一 DLL 必须能在 0.113.1 加载并工作。

**SP-012** mod 只能引用 0.111.1 与 0.113.1 中都存在的游戏 API；新增或改名的 API 不得直接引用。

**SP-013** mod 不得修改卡名、卡图、基础费用、伤害、抽牌数，不得新增或禁用卡牌。

**SP-014** mod 不得依赖其他 mod；`sts2.dll` 与 `0Harmony.dll` 必须以 `Private=false` 引用。

## 5. 清单与构建

**SP-015** `RevertRocketPunch.json` 必须声明 `id=RevertRocketPunch`、`has_dll=true`、`has_pck=true`、`min_game_version=0.107.0`、`dependencies=[]`、`affects_gameplay=true`。

**SP-016** 发布版本的 manifest `version`、CHANGELOG、ChangeLog、README 与发布包文件名必须一致。

**SP-017** 构建前必须运行版本一致性门禁；门禁失败时不得继续构建。

**SP-018** 发布包必须包含 `RevertRocketPunch.dll`、`RevertRocketPunch.pck`、`RevertRocketPunch.json`，不得包含测试模组、日志或 `PRIVACY/` 内容。

## 注记（非规范性）

- 0.113.1 新增 `ara`，该语言在游戏中默认隐藏。官方 `ROCKET_PUNCH.description` 已为「降为 0」，因此不需要 mod 文本。
- 0.111.1 与 0.113.1 的 `RocketPunch.cs`、`CardEnergyCost.SetUntilPlayed`、`CardModel.Description`、`LocString`、`ReleaseInfoManager`、`ModManager` 均无影响本 mod 的差异。证据见 `3.DOCS/003-E-111.1与113.1兼容性核验.md`。

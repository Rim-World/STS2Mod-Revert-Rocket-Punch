# 版本 1.0（2026-08-21）

- **版本号**：1.0（`9.SRC/RevertRocketPunch/RevertRocketPunch.json` 的 `version`；游戏 `mods/RevertRocketPunch/` 内清单一致）
- **时间戳**：2026-08-21（构建与提交日；实现始于 2026-08-20，同日完成 ModelDb 修复与 107 文本对齐，版本号未递增）
- **开发人员反馈**：
  - 需求：把「火箭飞拳」从 v0.111 的「生成状态牌 → 耗能减少 1」回调为 v0.110 之前的「生成状态牌 → 耗能降为 0」。
  - 首次实机验证：mod 在 mods 菜单可见、已启用，但卡面文本与效果全部保持 111 原版，补丁完全未生效（ADR-002）。
  - 补充需求：游戏降级至 v0.107.1，要求解包 107 全部卡牌文本与效果作为参考库，并逐语言核对 mod 文本（ADR-003）。
- **实装更改概括**：
  - 新增 `RevertRocketPunch` mod：效果补丁（`SetUntilPlayed(0)`）+ 描述切键（`RE_ROCKET_PUNCH.description`）+ 卡存在性守卫 + 版本门（`Minor >= 110`）。
  - 提供 15 语言卡面描述（deu/eng/esp/fra/ita/jpn/kor/pol/ptb/rus/spa/tha/tur/zhs/zht），`ind` 不替换。
  - 修复 ModLoaded 阶段访问 `ModelDb` 导致的补丁未安装问题。
  - fra/spa 描述改用官方 107 的不换行空格（NBSP）。
- **简略技术细节**：
  - Harmony Prefix 短路 `RocketPunch.AfterCardGeneratedForCombat`，三重守卫（creator / card.Owner / `CardType.Status`）后 `EnergyCost.SetUntilPlayed(0)`。
  - `CardModel.Description` getter Postfix 切换到模组专属键，避免与覆写官方键的 mod 冲突。
  - `ModEntry.ModLoaded` 只做 `new Harmony(ModId)` + `PatchAll`，整体 try/catch；`ModelDb` 与 `SemVer` 一律运行时懒求值 + 缓存。
  - Godot 4.5.1 mono + net9.0，`has_dll/has_pck` 双产物；`build.ps1` 完成 dotnet 构建、Godot 导入与 export-pack、安装到 `mods/RevertRocketPunch/`。
- **失败经验或实验教训**：
  - `ModLoaded` 处于 `ExecuteVeryEarly`，早于 `ExecuteEssential` 的 `ModelDb.Init()`/`LocManager.Initialize()`；在 `ModLoaded` 里查 `ModelDb` 必然 `KeyNotFoundException`，被 catch 误判为「卡不存在」后跳过 `PatchAll`，mod 显示已加载却完全无效。运行期相关的检查必须推迟到补丁首次触发时懒评估。
  - 107 pck 内 `src/**/*.cs` 全是 1 字节占位，效果源码只能靠 ilspycmd 反编译 `sts2.dll` 获取；107 官方无 zht/ind 语言目录。
  - Steam 自动把游戏更新回 111 会覆盖参考库本地化目录，重跑提取脚本才能恢复纯 107 数据。

## 四、编译核验

命令：

```powershell
dotnet build 9.SRC/RevertRocketPunch/RevertRocketPunch.csproj -c Debug -t:Rebuild -p:Sts2DataDir="<0.111.1 引用目录>"
dotnet build 9.SRC/RevertRocketPunch/RevertRocketPunch.csproj -c Debug -t:Rebuild -p:Sts2DataDir="<0.113.1 引用目录>"
```

结果：

| 项 | 0.111.1 | 0.113.1 |
|---|---|---|
| 警告 | 0 | 0 |
| 错误 | 0 | 0 |
| DLL SHA-256 | `506137e69ba68a72f6e3e4def2ac8cfe43e0d8a7d2e6a02b39fbe43f3065f09c` | `0b27f5dc44e32c9a2ec0bb14dbcd855adfaa5bfdbbaf76b1f3c152f7c3105f65` |
| `call`/`ldftn`/`newobj` 成员引用 | 61 条 | 61 条，与 0.111.1 完全相同 |

两份 DLL 的哈希不同，差异来自程序集引用元数据；成员引用集合逐条相同，说明源码没有绑定任一版本独有的 API。

发布用 DLL 取 0.111.1 编译结果，SHA-256 `506137e6…`。部署到本机 0.113.1 `mods/RevertRocketPunch/` 后，该文件哈希保持不变。

## 五、0.113.1 运行验证

测试工件：

- 探针源码：`8.TEST/1.1/RocketPunchProbe/`
- 场景脚本：`8.TEST/1.1/场景-火箭飞拳探针.txt`
- 标准输出：`8.TEST/1.1/2026-11-19-0038-scenario.stdout`
- 游戏日志：`8.TEST/1.1/2026-11-19-0038-scenario-godot.log`

命令：

```bash
cd "/c/Game/Steam/steamapps/common/Slay the Spire 2"
SteamAppId=2868840 ./SlayTheSpire2.exe --headless \
  --scenario="<项目目录>/8.TEST/1.1/场景-火箭飞拳探针.txt" \
  --seed=RPTEST1 --fast-mode=Fast
```

结果：退出码 0，场景完成。关键日志：

```text
RevertRocketPunch: Harmony patches applied (Rocket Punch -> pre-v0.110 behavior)
RevertRocketPunch: current version v0.113.1 is supported; patches enabled.
[rp-probe] desc key=RE_ROCKET_PUNCH.description raw=造成 {Damage:diff()} 點傷害。
抽 {Cards:diff()} 張牌。
每當你創造一張狀態牌時，使此牌耗能降為 0 {energyPrefix:energyIcons(1)}，直到打出為止。
[rp-probe] before=2
[rp-probe] after_first=0
[rp-probe] after_second=0
[rp-probe] PASS
[Scenario] Scenario completed successfully: 场景-火箭飞拳探针
```

说明：

- 当前游戏语言为 `zht`，文本探针读到了 `RE_ROCKET_PUNCH.description`，原文为「降為 0」。
- 火箭飞拳加入手牌时费用为 2；连续生成两张状态牌后费用均为 0。
- 探针在场景结束后已从游戏 `mods/` 移出，保存在 `TMP/1.1/probe-deployed-20261119-0038/`。

## 六、结论与边界

结论：未发现阻止 0.111.1/0.113.1 双版本兼容的问题。1.1.0 的发布 DLL 以 0.111.1 编译，在 0.113.1 完成加载、效果与文本验证。

未验证：

- 0.111.1 实机运行。本机未安装该分支；需用户切换 Steam 分支后加载同一 DLL 并打一场。
- 视觉排版、动画、音效与多人联机。无头场景不渲染界面。
- `ara` 文本的长期稳定性。依赖 0.113.1 官方本地化，游戏更新后需复核。
- 0.113.0。参考库已标注弃用，不在兼容范围。

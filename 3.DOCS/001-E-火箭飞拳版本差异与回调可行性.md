# 调研：火箭飞拳（Rocket Punch）版本差异与回调可行性

- 日期：2026-08-20
- 目标：确认故障机器人卡牌「火箭飞拳」从 v0.110+「生成状态牌 → 费用 -1」回调为 v0.110 之前（v0.107.1）「生成状态牌 → 费用归零」所需的全部信息
- 当前游戏版本：v0.111.0（`release_info.json`：commit `41cef1ea`，date 2026-08-13，branch v0.111.0）

## 一、结论速览

- 只需补丁 1 处核心方法（`RocketPunch.AfterCardGeneratedForCombat`）：把 110+ 的 `EnergyCost.AddUntilPlayed(-1)` 改回 107 的 `EnergyCost.SetUntilPlayed(0)`，即完成效果回调。
- 必须同步覆写描述文本：111 官方文案为「耗能…减少 1」，107 为「耗能…降为 0」，不改会造成文字与效果不符。
- 被依赖 API（`AfterCardGeneratedForCombat` 签名、`CardEnergyCost.SetUntilPlayed`、`Player?` 类型）在 107/110/111 完全一致，单份产物三版本通用；min_game_version=0.107.0 由加载器原生保证。
- 已有同款实现先例：CustomCardBalance（`RocketPunchGeneratedStatusPatch`，效果与描述均已实现）；工程模板可完全复用「回调同步/回调王座」系列（形状守卫 + 版本门 + 写死补丁）。

| v0.111（当前） | `AddUntilPlayed(-1)` | 同 107 | `(CardModel card, Player? creator)` | `refs/decompiled-111/MegaCrit.Sts2.Core.Models.Cards/RocketPunch.cs:35-51` |

- 效果语义差异：**107**：生成状态牌后费用「绝对设为 0」直至打出（`SetUntilPlayed(0)`，Absolute 修饰符）；**110+**：费用「相对 -1」直至打出（`AddUntilPlayed(-1)`，Relative 修饰符）。
- 其余无差异：基础 2 费 / 攻击 / 罕见 / 任意敌人；伤害 13(+1)；抽 1(+1)；`OnPlay` 的 `FromCard(this)` 与 `FromCard(this, cardPlay)` 差异仅为 110 起的 API 签名扩展（携带打出上下文），不影响玩家可见效果，**无需回调**。
- 变化发生区间：v0.107.1 → v0.110 之间（108/109 无解包数据；107.1 是 110 前最后一个已确认版本，即用户所指「110 版本之前」的效果）。
- 注：火箭飞拳为 STS2 原创卡，STS1（本机 `SlayTheSpire/desktop-1.0.jar`）无此卡，无法从 STS1 借官方文本。

## 三、API 取证（111，与 107 一致）

| API | 位置 | 说明 |
|---|---|---|
| `RocketPunch.AfterCardGeneratedForCombat(CardModel, Player?)` | RocketPunch.cs:35 | public override Task；107~111 签名一致 |
| `CardEnergyCost.SetUntilPlayed(int cost, bool reduceOnly = false)` | CardEnergyCost.cs:175 | Absolute 修饰符，`WhenPlayed` 过期；107 源码为 `SetUntilPlayed(0)`（默认 reduceOnly=false），等价 |
| `CardEnergyCost.AddUntilPlayed(int amount, bool reduceOnly = false)` | CardEnergyCost.cs:258 | Relative 修饰符（被替换的目标） |
| `CardType.Status` | Entities.Cards | 107 源码直接比较 `card.Type != CardType.Status` |

`SetUntilPlayed(0)` 实现：`_localModifiers.Add(new LocalCostModifier(0, Absolute, WhenPlayed, reduceOnly))`，`GetWithModifiers` 中 Absolute 修饰符直接覆盖当前费用 → 与 107 行为一致。

## 五、参考实现

### 5.1 CustomCardBalance（效果补丁，已实战验证）

`refs/custom-card-balance-decompiled/CustomCardBalance/RocketPunchGeneratedStatusPatch.cs`：

```csharp
[HarmonyPatch(typeof(RocketPunch), "AfterCardGeneratedForCombat")]
public static class RocketPunchGeneratedStatusPatch
{
    [HarmonyPrefix]
    public static bool Prefix(RocketPunch __instance, CardModel card, Player? creator, ref Task __result)
    {
        if (!ModConfiguration.IsEnabled("rocket_punch")) return true;
        if (creator != __instance.Owner || card.Owner != __instance.Owner || card.Type != CardType.Status)
        {
            __result = Task.CompletedTask;
            return false;
        }
        __instance.EnergyCost.SetUntilPlayed(0, false);
        __result = Task.CompletedTask;
        return false;
    }
}
```

- 全部路径短路（含守卫失败分支）→ 补丁体完全自包含（「写死」哲学，见 5.2）。
- 描述覆写：`LocTable.GetRawText` Prefix + `LocTable.HasEntry` Postfix + `CustomLocalizationOverrides`（15 语言内嵌代码），直接覆写 `ROCKET_PUNCH.description` 官方键。

### 5.2 本系列工程模板（STS2Mod-回调同步 v1.2 / 回调王座）

- 结构：`src/<ModId>/`（ModEntry.cs + Patches/ + csproj + json + project.godot + export_presets.cfg + build.ps1）。
- ModEntry：`[ModInitializer("ModLoaded")]` → 形状守卫静态检查 → `Harmony.PatchAll`（try/catch 整体包裹）。
- 形状守卫（SynchronizeShapeGuard）：静态成员存在性 + 运行时 `ModelDb.Card<T>()`；任一失败 → 整体禁用 + Log.Warn，不崩溃。
- 版本门（ModConfig.IsActiveVersion）：`ReleaseInfoManager.Instance.SemVer` 懒求值 + 缓存，未就绪暂放行。
- 文本切键模式（SynchronizeTextPatches）：本地化用 `RE_` 前缀专属键（`RE_SYNCHRONIZE.*`），patch `CardModel.Description` getter 切换到新键，避免与其他 mod 覆写官方键冲突；pck 内放 16 语言 json。
- manifest：`min_game_version: "0.107.0"`、`has_pck/has_dll: true`、`affects_gameplay: true`。
- 构建：`dotnet build -c Debug`（Godot.NET.Sdk/4.5.1 + net9.0，引用本机 `sts2.dll`/`0Harmony.dll`，`NoWarn MSB3270`）→ Godot `--headless --import` → `--export-pack` → 拷贝 dll/pdb/json 至 `游戏目录/mods/<ModId>/`。

## 六、兼容性要点

- 目标方法 `AfterCardGeneratedForCombat` 在 107/110/111 签名一致（103.2 及更早为 `bool addedByPlayer`，已被 min_game_version 排除）。
- 110→111 已确认无相关 API 变化（`refs/v110-to-v111-compat.md`：`CardCmd`/`CardModel` 关键 API 均一致；111 新增第 16 语言 ind）。
- 形状守卫建议项：`RocketPunch` 类型、`AfterCardGeneratedForCombat` 方法、`CardEnergyCost.SetUntilPlayed` 方法、`ModelDb.Card<RocketPunch>()` 存在性。
- 版本门建议项：`SemVer.Minor >= 110` 才生效（107/108/109 已是目标效果，不干预；110+ 一律修正为 107 效果，面向未来版本）。
- 未来版本防护：任一守卫失败 → 补丁整体禁用，游戏保持原版行为。

# 版本日志 001

## 1.1.0（2026-11-19 00:24）

- **版本号**：1.1.0
- **时间戳**：2026-11-19 00:24
- **开发人员反馈**：正式版更新到 0.111.1，beta 版更新到 0.113.1；要求同一份 mod 同时兼容两个版本，并按新版 AGENTS.md 重整仓库。
- **实装更改概括**：
  - 兼容基线锁定 0.111.1 与 0.113.1；发布 DLL 以 0.111.1 程序集编译。
  - 新增 `ind` 卡面描述，修复印尼语「效果已回调、文本仍写减少 1」的不一致。
  - manifest 版本从 `1.0` 升至 `1.1.0`。
  - 仓库目录迁移为 `1.PRD`、`4.ADR`、`5.SDD`、`6.SPEC`、`7.ChangeLog`、`8.TEST`，补 PRD、SPEC、测试索引与版本门禁。
- **简略技术细节**：
  - `RocketPunchTextPatch.IsSupportedLanguage` 白名单加入 `ind`；本地化生成脚本改到 `9.SRC` 路径并输出 16 语言。
  - `export_presets.cfg` 的 `export_files` 加入 `ind/cards.json`。
  - `8.TEST/CI-CD/verify-version.ps1` 校验 manifest、`CHANGELOG.md`、`7.ChangeLog/ChangeLog.md` 的版本号；`build.ps1` 在构建前调用。
  - `build.ps1` 支持 `-Sts2DataDir`，可用参考库中的 0.111.1 程序集编译。
  - 0.111.1 与 0.113.1 的 `RocketPunch.cs`、`CardEnergyCost.SetUntilPlayed`、`CardModel.Description`、`LocString`、`ReleaseInfoManager`、`ModManager` 无影响本 mod 的差异；同一份成员引用集合可对两版程序集编译。
  - 0.113.1 无头场景探针通过：费用 2 → 0 → 0，`Description` 键为 `RE_ROCKET_PUNCH.description`；发布包为 `RevertRocketPunch.v1.1.0.zip` 与 `RevertRocketPunchSourceCode.v1.1.0.zip`。
- **失败经验或实验教训**：
  - 重跑本地化脚本会覆盖已有的 NBSP 修正；`fra`、`spa` 的 `0` 与 `{energyPrefix}` 之间必须使用 NBSP（`\u00a0`），脚本已固化。
  - 0.113.1 新增 `ara`，但官方阿拉伯语描述已经写「降为 0」，因此不加入切键白名单；否则会多维护一份无必要的文本。
  - 0.113.1 的 `LocManager` 把 `ara` 放入隐藏语言集合，正常界面不可选，不能按「新增语言」直接推断需要 mod 文本。
- **待做或待决定**：
  - 0.111.1 运行验证需用户切换 Steam 分支后手动完成；本机当前安装为 0.113.1。
  - 0.113.1 的 `ara` 文本是否长期保持「降为 0」需在下次游戏更新后复核。
- **提交编号**：待回填

## 1.0.1（2026-08-20）

- **版本号**：manifest 仍为 `1.0`；本节记录构建标记 1.0.1。
- **时间戳**：2026-08-20
- **开发人员反馈**：首次实机验证发现 mod 显示已加载，但卡面文本与效果全部保持 111 原版。

- **待做或待决定**：无。
- **提交编号**：`199887f`
